# 油站停车预约调度

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在原「油站网点地图管理」基础上补齐的停车预约闭环。旧油站数据（`hxwlfront-21-station-map`）照常只读引用；停车预约数据独立保存在浏览器 localStorage 键 `hxwlfront-21-parking`。

## 业务规则

- 登记车牌、油站、入场时刻、停留时长；车牌自动大写归一。
- 同一车牌在同一油站时间重叠的有效预约只保留一条（含候补/已分位/在场/逾期）。
- 危化品车只分配危化品专用位，不占普通车位；两类车位分别计数、分别候补。
- 对应车位池满后进入候补；有车位释放时按登记时间先后自动补上，轮到危化品车分配的是专用位。
- 超过入场时刻 15 分钟未签到，车位自动释放，最早候补接上；候补补上时若其入场时限也已过，则直接判逾期并继续补下一辆。
- 站点暂停营业后不接受新预约，也不再补位；已经入场的车辆仍可正常签退，恢复营业后候补继续。

## 代码结构（规则 / 存储 / 页面接入分层）

```
src/parking/
  types.ts       领域模型（预约、站点、状态、输入输出类型）
  rules.ts       规则层：纯函数，去重、车位计数、候补晋升、逾期结算，不碰 DOM/localStorage
  storage.ts     存储层：旧油站数据读取、预约数据读写与脏数据清洗
  selectors.ts   展示辅助：状态文案、时间格式化、指标汇总
  store.ts       页面接入层（Pinia）：组合规则与存储、定时结算、跨标签页同步
  ParkingView.vue
  components/    登记表单、预约列表、站点车位面板
```

- 列表按状态分组展示，可按状态与油站筛选；已分位单子显示签到倒计时。
- 指标卡显示占用、候补、逾期与在场车辆数；站点面板显示两类车位占用条与候补数。
- 每 20 秒自动结算一次，切换标签页回来立即结算；同一浏览器跨标签页数据实时同步。
